Machine Learning Foundation on GitHub

Interactive explorables

Drag, slide and click to build intuition for the ideas in each module. Everything runs in your browser, with nothing to install, and every chart updates as you move a control.

Module 01 · Regression

Fitting a line

Drag points, move the line, and see the squared errors, the loss landscape and gradient descent's path update live.

 Modules 01 & 03 · Overfitting

Bias and variance

Fit polynomials to many resampled datasets and watch the fits spread apart as the degree grows.

 Module 01 · Regularisation

Ridge vs Lasso

See the geometry behind regularisation, and why the L1 diamond sets weights exactly to zero.

 Modules 00 & 05 · Optimisation

Optimiser race

Race gradient descent, momentum, RMSProp and Adam across a narrow bowl, a banana valley and a surface with two minima.

 Module 00 · Probability

Spread and averages

Move μ and σ, draw samples, check the 68–95–99.7 rule, and watch the central limit theorem shrink the spread of averages.

How these are built

Plain HTML, CSS and JavaScript drawn on <canvas>, with no libraries or build step. The maths lives in assets/mlmath.js and is checked against NumPy, scikit-learn, SciPy and PyTorch by tests/mlmath.test.js.

Part of Machine Learning Foundation. The theory is in each module's README, and the from-scratch code is in the notebooks.
