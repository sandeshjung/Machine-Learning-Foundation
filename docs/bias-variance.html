Bias and variance: how the fits spread

Draw many training sets from the same process, fit the same polynomial to each, and look at how the fitted curves disagree. Simple models all make the same mistake (bias). Complex models make different mistakes every time (variance).

What to try

  1. Degree 1. Every fit is almost the same straight line, so the variance is tiny. But they all miss the curve in the same way, so the bias is large. This is underfitting.
  2. Degree 3 to 5. The fits hug the true curve and stay close together. Bias and variance are both small, and the test error is near its lowest.
  3. Degree 12 to 15. Each fit passes close to its own points but swings wildly between them and at the edges. The fits now spread out a lot, so the variance explodes. Training error keeps falling while test error shoots up. This is overfitting.
  4. More data. Stay at degree 12 and raise the points per training set to 100. The spread shrinks: more data reduces variance.
  5. No noise. Set σ to 0. Even high degrees behave much better, because there is no noise for the model to chase.

What's going on

Each training set has 20 points drawn from y = sin(2πx) + noise. For every degree, the page fits one polynomial per training set and then, at each x:

  • bias² compares the average fit (orange) with the true curve (green),
  • variance measures how much the individual fits spread around their average,
  • noise σ² is the randomness in y that no model can predict.

The expected error on new data is exactly their sum. The bias² and variance shown are averaged over x in [0, 1].

One caveat: at very high degrees the measured bias² rises too. The average of a few dozen wildly different fits is itself noisy, so part of the variance leaks into the bias estimate. Increase the number of training sets and that part shrinks.

expected test error = bias² + variance + σ²
The best degree is where the test error curve bottoms out. In practice you can't draw fresh training sets, so you estimate that point with a validation set or cross-validation.
