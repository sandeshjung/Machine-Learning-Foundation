GD starts from your current (w, b). Each step: w ← w − η·∂MSE/∂w, b ← b − η·∂MSE/∂b.

What to try

  1. Fit it by hand. Move the slope and intercept until your MSE is as low as you can get it. Then tick Show least-squares line to see how close you came.
  2. See what MSE measures. Tick Show squared errors as boxes. The MSE is the average area of the boxes, so one far-away point has a huge box. Drag a point far from the others and watch the best line swing towards it: MSE is sensitive to outliers.
  3. Spread the data. Raise the noise σ. The best line barely moves, but the best possible MSE grows (roughly as σ²) and R² falls. No line can remove that noise.
  4. Few points, wobbly line. Set the number of points to 3–5 and click New random data a few times. The fitted line jumps around a lot. That is variance, and more data reduces it.
  5. Run gradient descent. Drag the dot on the landscape somewhere far from the ×, then press Run. The path zig-zags down a long, narrow valley. Now raise the learning rate above about 0.03 and run again: the steps overshoot and diverge.

What's going on

The model is a straight line, ŷ = w·x + b. Its error is the mean squared error:

MSE(w, b) = (1/m) · Σᵢ (w·xᵢ + b − yᵢ)²

Every (w, b) has an MSE, and the right-hand panel colours each one. The MSE is a quadratic in w and b, so the landscape is a bowl with a single lowest point. That point is the least-squares line, and it can be computed directly with the normal equation.

Gradient descent finds the same point step by step, always moving downhill:

∂MSE/∂w = (2/m) · Σᵢ (ŷᵢ − yᵢ)·xᵢ     ∂MSE/∂b = (2/m) · Σᵢ (ŷᵢ − yᵢ)
Why the valley is long and narrow. The x-values run from 0 to 10, so a small change in w moves the line a lot more than the same change in b. The bowl is very steep in the w direction and very flat in the b direction. Gradient descent needs a learning rate small enough for the steep direction, which makes it crawl along the flat one. Standardising the features (zero mean, unit variance) makes the bowl round and gradient descent much faster.
