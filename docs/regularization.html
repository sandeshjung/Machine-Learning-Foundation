What to try

  1. Lasso, slowly raise α. The blue solution slides from ŵ towards the origin. At some point it hits an axis: one weight becomes exactly 0. Raise α further and the other one reaches 0 too. That is feature selection.
  2. Switch to Ridge. The same α only shrinks both weights. The solution curves smoothly towards zero but never lands exactly on an axis.
  3. Drag ŵ around with Lasso on. For a wide range of positions the solution snaps to a corner of the diamond, because the corners stick out towards the error contours.
  4. Correlated features. Set the correlation to 0.8. Lasso tends to keep one of the two features and drop the other. Ridge shares the weight between them.

What's going on

For two standardised features with correlation ρ, the mean squared error around the least-squares solution ŵ is (up to a constant) a quadratic bowl:

J(w) = ½ (w − ŵ)ᵀ H (w − ŵ) + α·Ω(w),    H = [[1, ρ], [ρ, 1]]

The rings are the contours of the first term. The solution of the penalised problem sits where an error contour just touches the penalty region of the same size (the shaded circle or diamond):

  • The L2 circle is smooth, so the touching point is almost never exactly on an axis. Ridge shrinks, but keeps every feature.
  • The L1 diamond has corners on the axes, and an ellipse usually reaches a corner first. At a corner one weight is exactly zero, so Lasso selects features.
Libraries scale α differently. This page uses α·Ω(w) added to ½(w − ŵ)ᵀH(w − ŵ). That is the same as scikit-learn's Lasso(alpha=α), and the same as its Ridge with alpha = 2·m·α for m samples.
